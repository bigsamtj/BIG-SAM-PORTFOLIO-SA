## 🎬 Portfolio Design

This portfolio was designed as a **cinematic digital experience** rather than a conventional developer portfolio.

The interface combines:

- Dark cinematic visual language
- Red accent system
- GSAP-powered animations
- Scroll-driven interactions
- Responsive layouts
- Interactive cards
- Mobile swipe interactions
- Parallax effects
- Custom cursor interactions
- Motion-based storytelling

The goal is to combine **engineering, cybersecurity, investigation, and visual storytelling** into a single digital experience.
